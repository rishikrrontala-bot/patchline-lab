## What would strengthen the first three categories further

1. **Domain and workflow proof:** a permissioned, non-patient benchtop recording with independently reviewed units, source readings, expected findings and reference provenance. The UCI recording proves environmental interoperability; it does not validate a wearable sensor. Compare a correct complete reporting task against the participant's actual current workflow and record errors, completion, setup, assistance and time.
2. **Buyer and price proof:** a real budget-owner response to the exact capped pilot, a purchasing route and measured delivery effort. The default hypothetical labor value is only $40/month against $99 pricing. Record evidence supporting a different frequency, value or price, and retain objections and negative outcomes.

The [validation kit](CUSTOMER-VALIDATION-KIT.md) supplies the worksheets. Preparing them does not create interview evidence or authorize outreach. Buyer research is a score-improving evidence goal, not an additional hackathon eligibility rule.

No judge score is guaranteed. “95+” is an aspiration across technical execution, innovation/UX and business/finance; acceptance tests verify delivered behavior, while originality, user value and financial sustainability still depend on evidence the tests cannot manufacture.
