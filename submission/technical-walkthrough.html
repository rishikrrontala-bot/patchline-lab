01 · Bounded, confirmed input

Columns and units are confirmed before import. Seconds/milliseconds, temperature and wetness conversions are explicit. Blank selected readings remain missing; unselected sensors remain absent. No units are inferred from raw voltages.

export function parseMappedCSV(text, profile = DEFAULT_PROFILE, filename = 'experiment.csv') {
  if (typeof text !== 'string') throw new Error('text must be string');
  if (typeof filename !== 'string' || filename.length > MAX_FILENAME) throw new Error('Invalid filename');
  const validated = validateProfile(profile);
  const { headers, rows } = scanCSV(text);
  const colIndex = Object.create(null);
  headers.forEach((h, i) => { colIndex[h] = i; });
  const timeIdx = colIndex[validated.timeColumn];
  if (timeIdx === undefined) throw new Error('Time column not found in CSV');
  const channelIdx = {};
  for (const k of Object.keys(validated.channels)) {
    const idx = colIndex[validated.channels[k].column];
    if (idx === undefined) throw new Error('Channel column not found: ' + validated.channels[k].column);
    channelIdx[k] = idx;
  }
  const selectedKeys = Object.keys(validated.channels).sort((a, b) => KEYS.indexOf(a) - KEYS.indexOf(b));
  const samples = [];
  let prevTime = -Infinity;
  for (let r = 0; r < rows.length; r++) {
    const row = rows[r];
    const timeRaw = row[timeIdx];
    const timeNum = parseFiniteNumber(timeRaw);
    if (timeNum === null) throw new Error('Non-numeric timestamp at row ' + (r + 1));
    if (timeNum < 0) throw new Error('Negative timestamp at row ' + (r + 1));
    let t = timeNum;
    if (validated.timeUnit === 'ms') t = timeNum / 1000;
    if (!(t > prevTime)) throw new Error('Timestamps not strictly increasing at row ' + (r + 1));
    prevTime = t;
    const sample = { t };
    for (const k of KEYS) {
      if (selectedKeys.includes(k)) {
        const idx = channelIdx[k];
        const raw = row[idx];
        if (raw.trim() === '') {
          sample[k] = null;
        } else {
          const num = parseFiniteNumber(raw);
          if (num === null) throw new Error('Non-numeric ' + k + ' at row ' + (r + 1));
          sample[k] = convertValue(k, validated.channels[k].unit, num);
          if(!Number.isFinite(sample[k]))throw new Error('Unit conversion overflows finite range');
        }
      } else {
        sample[k] = null;
      }
    }
    samples.push(sample);
  }

04 · Export the applied analysis

Reports require the matching engine-produced analysis and protocol. The UI adds the applied reference/options. Workspace validation and comparison are completed before state replacement, so a failed restore preserves the current investigation.

export function createReport(trace, result, benchmark = null, protocol = DEFAULT_PROTOCOL) {
  validateProtocol(protocol);
  const record = ANALYSES.get(result);
  if (!record || record.trace !== trace) throw new TypeError("Report requires the matching analyzed experiment");
  if (JSON.stringify(record.snapshot.protocol) !== JSON.stringify(protocol)) {
    throw new TypeError("Report protocol must match the analyzed experiment");
  }
  if (benchmark !== null && !BENCHMARKS.has(benchmark)) throw new TypeError("Benchmark must come from a local benchmark run");
  return {
    schema: "patchline-lab-experiment/v1", version: VERSION,
    ...copyJSON(record.snapshot),
    units: { temperature: "°C", moisture: "%", ph: "pH", glucose: "AU" },
    benchmark: benchmark === null ? null : copyJSON(benchmark),
    scope: "Research sensor validation only; no clinical diagnosis or treatment.",
  };
}

06 · Scale and boundaries

Quality checks scan every selected channel. Reference alignment advances through ordered arrays. Chart reduction affects display only; evidence and exports retain every row. Current bounds: 1 MiB / 5,000 CSV rows, 4 MiB workspace, 32 KiB protocol. Per-tab processing avoids a shared compute bottleneck; larger streaming files, team accounts and collaboration require a separate architecture.

The inherited shape-only fault benchmark still detects 75 / 100 injected faults, misses 25 smooth drifts, and flags 0 / 100 clean traces. Reference comparison is additional evidence and does not rewrite those historical results.

GLM 5.2 generated add-on code as a coding assistant. Local review corrected the implementation; independent tests verify behavior. Featherless credentials and generation logs are absent from the release. The application never calls an AI provider.
